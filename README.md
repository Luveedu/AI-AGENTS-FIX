# AI-AGENTS-FIX

A comprehensive collection of specialized skill definitions for AI coding agents. This repository provides ready-to-use skill configurations that enhance AI agent performance across various development domains.

## 📚 Available Skills

| Skill | Description | Use Case |
|-------|-------------|----------|
| **frontend-design** | Distinctive, intentional visual design for web UI | Building new pages, reshaping designs, establishing aesthetic direction, typography, deliberate design decisions |
| **mobile-ui-ux** | Elite Tailwind CSS mobile-first UI/UX optimization | Mobile layouts, responsive design, touch targets, typography scaling (320px-768px) |
| **project-guide** | Strict AI agent governance and project consistency protocols | Building new pages, editing components, enforcing zero-assumption mandates, design consistency |
| **seo-content** | Elite SEO architecture, technical auditing, EEAT-focused content strategy | URL/keyword analysis, SEO-optimized content, technical audits, anti-AI human-grade writing, schema markup |
| **speed-optimization** | Elite web performance optimization for PHP-based sites | PageSpeed analysis, render-blocking resources, CSS/JS/font optimization, CLS reduction, caching strategies |

## 🚀 Quick Setup

Use the automated setup script to install skills directly into your AI editor's configuration folder:

```bash
curl -fsSL https://raw.githubusercontent.com/Luveedu/AI-AGENTS-FIX/refs/heads/main/setup.sh | bash
```

The script will prompt you to select your AI code editor and automatically download all skills to the appropriate directory.

## 💡 How to Use

1. **Run the setup script** - Select your AI editor from the interactive menu
2. **Skills are downloaded** - Each skill is placed in `<editor-folder>/skills/<skill-name>/SKILL.md`
3. **Enable in your editor** - Your AI agent will automatically detect and use these skills
